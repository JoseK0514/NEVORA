# Component picks (Jose, Nov 22, 2026)

`ComponentStyle` treatments in `src/components/premium/treatments.tsx`). Screens adopt these as they are redesigned.
**Final (Nov 22, 2026).** Jose asked for Claude's recommendation on the five flagged picks and took it: one solid teal
style for every main action (the saving button too), white raised cards (dark stays for pay and timecard totals and the
Clocker's receipt and unconfirmed screens), calm action cards for empty and result messages, outlined fields everywhere,
and Phosphor bold icons (DESIGN.MD). The bold rows below mark those changes.
