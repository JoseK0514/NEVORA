## What the bot backend can now do

The explicitly selected provider adapter supports the existing stateless Responses route and the documented Neon unified Chat Completions wire format. This allows a compatible branch-available model from a broader catalog to be evaluated, without replacing the agent or changing the frontend. Omitted API style preserves the existing route. Responses-only low/medium/high reasoning effort is optional and explicit. Chat supports bounded text/content-block results and multiple calls, processed sequentially. Native OpenAI Chat and Neon use their respective4096-token parameter names. No model-name guessing, model fallback, automatic retry or extra paid critic call was added.

Each operational read receives a fresh investigation-local evidence ID, scope, observation time and partial status. Saved goals express Owner intent; notes and old chat remain historical claims. The local `review_decision` function checks a concise decision's structure, retrieved references, current scope, separate options/tradeoffs, canonical coverage alternative, partial-data acknowledgement, recommendation, next step and outcome check. Bad references or structure return bounded correction codes. A failed review cannot be bypassed by returning prose. Simple factual answers and necessary questions remain compatible.

An accepted structured decision renders as the existing `answer.text` with server-owned citations/workflow data. Single workflow cards belong to the selected option's current references. No recommendation or no matching reference attaches no implicit last-read work. Multiple distinct selected periods/proposal sets omit the ambiguous single card with a source-owned explanation. Canonical coverage choices retain their exact actual alternative; remaining blocks, excluded locations, search limits, publication implications and hypothetical scope stay visible. Financial readiness remains unverified.

These checks validate references/structure/canonical plan identity, **not arbitrary prose truth or live-model intelligence**. A real model can still misinterpret evidence. No business executor, notification, payroll approval, publication consent, background monitoring or new standing authority was added. Next-step/outcome-check text does not execute follow-through.
