## Interface contract

Define in `types.ts`:

- `AttendanceSource`: `version:1`, `workspaceId`, `timeZone`, `observedAt`, `entries`, `publications`, `coverage`.
- `coverage`: booleans `entriesComplete`, `breaksComplete`, `publicationsComplete`.
- `RecordedEntry`: `id`, `workspaceId`, `employeeId`, `locationId`, `sourceVersion`, `clockInAt`, nullable `clockOutAt`, `status`, unknown `scheduleContext`, readonly `breaks`.
- `RecordedBreak`: `id`, `timeEntryId`, `startAt`, nullable `endAt`, nullable `breakTypeId`, unknown `breakTypeSnapshot`.
- `HistoricalShift`: `workspaceId`, `employeeId`, `locationId`, `revisionId`, positive `revisionNumber`, `publishedShiftId`, `scheduleId`, nullable `sourceShiftId`, `date`, `startTime`, `endTime`, `isCalloutApproved`.
- `ValidatedAttendanceSource`: the safe normalized envelope and readonly entries/publications; timestamps are checked in the responsible evaluator as described below. This type is not an authorization proof.
- `UnavailableProjection`: `{state:"unavailable";reason:"invalid_source"|"incomplete_source"|"source_limit"}`.
- `ScheduleEvidence`: discriminated `matched` with `startAt`, `endAt`, captured `timeZone`, `revisionId`, `publishedShiftId`; `unmatched` or `ambiguous` with recorded reason; or `not_evaluated` with a bounded limitation reason. Never return an arbitrary competing shift.
- `ObservationKind`: the seven exact uppercase kinds in spec section 6.
- `Observation`: stable `id`, `kind`, nullable `breakId`, fixed factual `message`, and minimal validated `evidence`; measured positive differences are base-10 `differenceNanoseconds` strings of 1–30 digits, with no leading zero. Evidence may contain only validated `recordedAt`, `expectedAt`, `differenceNanoseconds`, `targetMinutes`, `revisionId`, `publishedShiftId` and a bounded reason code; omit fields not applicable to that kind.
- `AttendanceGroup`: safe entry/employee/location IDs, sourceVersion, readonly observations; actual-time evidence is omitted for inconsistent history.
- `ReadyProjection`: `{state:"ready";engineVersion:1;workspaceId;timeZone;observedAt;scope;groups;recordCount;signalCount;affectedEmployeeCount;coverage}`. `scope` is `{kind:"TODAY_AND_OPEN";localDate:string;dayStartAt:string}`. `coverage` is `{state:"complete"|"limited";limitations:readonly ComparisonLimitation[];deferredCapabilities:readonly DeferredCapability[]}`; complete means complete for implemented recorded-time checks only.
- `ComparisonLimitation`: `{entryId:string;breakId:string|null;reason:LimitationReason}`. Reasons: `schedule_not_captured`, `schedule_context_invalid`, `schedule_reference_missing`, `schedule_reference_invalid`, `schedule_time_unresolved`, `publication_source_incomplete`, `break_target_not_captured`, `break_target_invalid`, `time_history_inconsistent`. Sort/deduplicate by entry, break and reason.
- `DeferredCapability`: `missing_clock_in`, `policy_lateness`, `policy_early_departure`, `unusually_long_entry`, `correction_review`, `overtime_risk`; include the same ordered list in every ready result.
- `AttendanceProjection = ReadyProjection | UnavailableProjection`.

Functions:
- `validateAttendanceSource(value: unknown): ValidatedAttendanceSource | UnavailableProjection`
- `resolveHistoricalSchedule(source: ValidatedAttendanceSource, entry: RecordedEntry): ScheduleEvidence`
- `projectAttendance(source: unknown): AttendanceProjection`
- `formatAttendanceDifference(differenceNanoseconds: string): string`

Synthetic helpers:
- `makeAttendanceSource(overrides?: Partial<AttendanceSource>): AttendanceSource`
- `makeRecordedEntry(overrides?: Partial<RecordedEntry>): RecordedEntry`
- `makeHistoricalShift(overrides?: Partial<HistoricalShift>): HistoricalShift`

Factories use explicit synthetic IDs and UTC instants. Tests explicitly set captured schedule context and timezone. They never borrow real QA IDs or access the hosted Preview.
