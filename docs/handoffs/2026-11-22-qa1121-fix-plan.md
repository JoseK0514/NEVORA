## Density rules (added to nevora-design-os in step 0.3)

1. Each fact appears once per screen.
2. A row is a title plus one line; a third line only for an exception (for example "Clocked in late").
3. The band holds the title and at most three figures; filters, notes and cards go below it.
4. One main action per card; other actions in a ⋯ menu.
5. Explanations show once (first visit, empty state or an info button), not on every visit.
