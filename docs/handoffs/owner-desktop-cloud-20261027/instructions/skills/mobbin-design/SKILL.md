# Mobbin Design

Read [references/DESIGN.md](references/DESIGN.md) before implementing a Mobbin-inspired interface. It contains the complete getdesign reference: color tokens, typography, spacing, component geometry, interaction patterns, and design rules.

Apply its gallery-white surfaces, monochrome hierarchy, pill controls, and restrained blue accent as a coordinated visual system. Adapt the reference to the requested surface and the project's existing components, explicit brand requirements, and accessibility needs. Keep the application's own content and identity.

The reference is VoltAgent's independent analysis of Mobbin's public design language, distributed through [getdesign](https://getdesign.md/mobbin/design-md).
