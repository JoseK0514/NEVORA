# Direction B: approved mocks

These are the mocks Jose approved for the Direction B redesign (Nov 2026). Each is a
self-contained HTML page (open it in a browser); most show today's screen beside the new
one. The built result and every later refinement are recorded in `DESIGN.MD`, which is the
source of truth when a mock and the app differ.

| File | Surface |
|---|---|
| `mocks/1-mobile-owner-employee.html` | Owner and Employee phones (the first Direction B board) |
| `mocks/2-owner-desktop/owner-desktop-direction-b.html` | Owner and Manager desktop |
| `mocks/3-employee-mobile/employee-mobile-direction-b.html` | All Employee phone pages |
| `mocks/4-lead.html` | Lead, phone and desktop |
| `mocks/5-employee-desktop.html` | Employee desktop |
| `mocks/6-tablets.html` | Tablets 768–1023 (Option B "small desktop" was chosen) |
| `mocks/7-sign-in-and-public.html` | Sign-in, recovery, activation, policy pages, 404 |
| `mocks/8-clocker.html` | Clocker kiosk (round 2, with Jose's six upgrades) |

`MOCK-BRIEF.md` is the brief the mock agents worked from (the system's colours, type,
radii and data rules).

Screenshots of the built app come from the harness in `tools/ui-scan/`.
