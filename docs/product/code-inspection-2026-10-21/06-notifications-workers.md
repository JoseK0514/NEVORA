# Slice 6: Notifications, push & background work (inspector report)

1. HIGH — Service worker silently drops six server-supported push kinds. public/fuel-portal-sw.js:142-160 whitelist omits COVERAGE_INVITATION, COVERAGE_CANCELLED, COVERAGE_EXPIRED, SWAP_CANCELLED, SWAP_EXPIRED, COMMUNICATION (server builds them: payloads.ts:4, recipients.ts:176,178). Delivery recorded provider_accepted but user never sees it — incl. the flagship coverage push. Drift since 50407eb3; hand-maintained test lists also omit them (service-worker.test.ts:128, payloads.test.ts:17-23). Title/body duplicated between payloads.ts and worker (second drift risk). Fix: worker builds title/body from kind with unknown-kind generic fallback; parity test importing the server kind list.
2. HIGH — Transient infra error becomes irreversible cancellation. notification-state.ts:187-202 catch-all → rejected('workspace_unavailable'); payroll notices.ts:71; worker.ts:122-125 maps every non-expired reason to terminal 'cancelled'; reminders.ts:236-241 cancelCurrentIntent; daily-budget NOT EXISTS (reminders.ts:83-84) counts cancelled rows so reminders can't regenerate. One Neon blip permanently loses the notification; payroll notices one-shot. Inbox code handles these reasons correctly by throwing; worker/reminders don't. Fix: treat *_unavailable and workspace_changed as transient — release/defer without spending attempt; reminders skip, keep intent; add tests.
3. MEDIUM — Post-send completion runs under pre-deadline budget → duplicate pushes. worker.ts:93-98 (limits.call cleanup=false throws at remaining()<=1000), margin check at :143 before decryption/second check (:178-179); send ≤8s; provider-accepted finish refused near 20s budget → lease expires 120s later → re-send. Fix: use cleanup (full-budget) signal for post-send finish/defer; re-check margin just before send; 19s-accept test.
4. MEDIUM — No key-rotation path; rotation locks out every installed device. installation.ts:19-47,77-96 ('v1.' tag, no key id); config.ts:11-16; subscription-service.ts:208-209; worker.ts:147-159; provider.ts:102. Rotation → 365-day HttpOnly cookie unreadable → 409 installation_conflict with no self-heal; ciphertext undecryptable → failed/subscription_material without invalidating subscription; UI still "enabled". VAPID mismatch same shape: 401/403 terminal with no breaker; device-client.ts:351 subscribe() throws on applicationServerKey change with no unsubscribe/resubscribe. Fix: key id + keyring; undecryptable cookie → mint new proof; invalidate subscription on persistent material failure; client re-subscribe path.
5. MEDIUM — Throughput cap, no urgency lane. push-deliveries.ts:53 (claim ≤10, lease 120), :80 ORDER BY next_attempt_at,id; worker.ts:238 LIMIT 10; check() runs twice reading whole week state (notification-transactions.ts:139-160). ~8-10 deliveries/20s; publication to 200 employees ≈30 invocations; 07:00 quiet-hours burst; urgent ≤12h shift-change queues FIFO. Fix: order by urgency; cache week-state per source per invocation; second check as version check; configurable batch.
6. MEDIUM — Deterministic pre-send failures released with no backoff → poison-pill loop. worker.ts:188 (buildPushEnvelope throws on unknown type), :221-226 release keeps next_attempt_at (push-deliveries.ts:120-128). Ten bad rows starve queue. Latent: 'clock-review' topic exists (alert-choices.ts:3, 0033, profile UI) but nothing emits its types and payloads/worker reject them — wiring a producer creates poison pills; today the toggle controls nothing. Fix: deterministic errors → terminal failed with error_class, or backoff on release; finish or remove clock-review.
7. LOW-MED — SW push handler can end without showing a notification (fuel-portal-sw.js:165-172): silent return on unowned generation/invalid/expired/storage failure → Chrome generic notice; iOS can revoke after repeated silent pushes. Fix: generic fallback showNotification except deliberate ownership-suppression.
8. LOW — Manager summary seeds can spin until expiry after a 0033 opt-out between seed creation and group build (summary inserted cancelled; seed-materialize requires cancelled_at IS NULL; seed branch never calls recipientAlertOn) — reminders rebuild/no-op up to 72h, filling the 100-row reconciliation window (0033 trigger; reminders.ts:210-227,136). Fix: check recipientAlertOn in seed branch and cancel seed. Delivery-time opt-out checks otherwise correct.
9. LOW — No dead-letter surface/monitoring/retention/in-repo scheduler. vercel.json no crons; worker run reports only in HTTP response; nothing deletes old push_deliveries/notifications/calendar_removals; dispatch coupled to cleanupRemovedSessions (worker.ts:229) — slow cleanup aborts run 503. Fix: per-run heartbeat+counters, staleness alert, retention job, decouple cleanup.
10. LOW — Dead legacy readers/writers bypass authority pipeline: src/lib/data/notifications.ts:35,67,95,111,130 (createNotification/listNotifications, no non-test callers; listNotifications ignores environment/cancellation/authority/payroll rules). Fix: delete or make test-private.
11. LOW — Calendar feed sound (hashed 256-bit token, revocation triggers, post-read authority recheck, no-store). Edges: no rate limit on public route; "active" CTE LIMIT 501 ORDER BY sh.id → >500 events in −31/+180d window = permanent 503; token in URL path/access logs (inherent). Fix: edge rate limit; order+cap by date; ops log redaction.
12. LOW — Test gaps (transient reasons, budget-edge finish, SW/payload parity, urgency ordering, seed-outlives-opt-out, key rotation); brittle SQL surgery (reminders.ts:82-86 six-literal-space match; push-subscriptions.ts:66-68 regex over VALUES) fails loud but formatting-fragile; possible Edge enrollment gap: validatePushEndpoint (subscription-service.ts:47-52) allows only FCM/Mozilla/push.apple.com and forbids query strings → *.notify.windows.com/w/?token= rejected (unconfirmed); dismissalScope HMACs with raw root key not purpose-derived.

SUMMARY: core design healthy (intent-with-business-write atomicity, leases/fences, quiet hours correct+tested, delivery-time authority/opt-out re-checks, generic payloads, sound calendar tokens). Material problems operational: SW kind drift (1) and transient-as-cancelled (2) silently lose real notifications; key rotation (4) and throughput (5) bite at activation scale.
