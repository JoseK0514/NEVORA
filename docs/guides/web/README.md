# NEVORA web guides

These guides describe the workflows in the accompanying **development source**.
Use the generated distribution manifest to identify the application source and
the exact Markdown/PDF bytes. A guide, enabled setting or passing local test does
not establish that a hosted environment is activated or accepted for use.

| Reader | Guide | Start here for |
| --- | --- | --- |
| Owner | [Owner](owner.md) | Company setup, access, scheduling, recorded time and payroll review |
| Manager or Lead | [Manager and Lead](manager-lead.md) | Assigned management scope and the separate Lead self-service limits |
| Employee | [Employee](employee.md) | Activation, shifts, availability, requests, recorded time and pay statements |
| Owner using Rondo | [Rondo](rondo.md) | Current company evidence, saved priorities and reviewed coverage drafts |
| Developer | [Developer](developer.md) | Architecture, authority, safe local work and verification |
| Operator | [Operations](operations.md) | Admission, workers, monitoring, incidents, privacy cases and restore gates |

The guides cover the web app on desktop and mobile browsers. Native apps,
native push, store availability and physical-device acceptance are a separate
delivery track. The internal payroll calculator's source folder is also named
`native`; that name does not mean a native app is available.

Use the destinations actually offered to your signed-in role. Company feature
switches, payroll grants and current Manager scope can change which pages appear.
The English labels here may also vary with company vocabulary. A hidden page is
not a reason to use someone else's account or a copied deep link.

This bundle is source-based documentation, not a replacement for the separate
Claude-owned draft SOP. It does not copy, approve or supersede that master.
The [evidence index](sources.json) maps each guide to repository sources;
the linked [developer reference](../../development/developer-guide.md) and
[operating packet](../../runbooks/workforce-operations.md) provide more detail.

For a work question, contact your employer or manager. For an app problem, use
**More → Help** and the support contact shown there. Share the page, approximate
time and a safe description; never send passwords, invitation links, recovery
codes, bank details or pay documents.
