# NEVORA assisted recovery fonts

These assets reproduce the approved NEVORA Typeface reference, using the existing local assets from the reviewed `codex/nevora-typeface-visual-refresh-20261010` checkout. No font subscription or remote runtime request is required.

- `inter-variable.ttf`: Inter variable, body and interface text; SIL Open Font License in `OFL.txt`.
- `jetbrains-mono-variable.ttf`: JetBrains Mono variable, issued proof only; SIL Open Font License in `JetBrains-Mono-OFL.txt`.

Original provenance: the typeface review records Google Fonts commit `bd8f81ddb5c74d5c8897b36ad88b440266245103`. This task copies those approved font bytes, rather than fetching a new font version. The root `DESIGN.MD` declares the two families.
